# Capturas reales del template

Capturadas el 2026-10-17 con Chromium y Playwright, sin modificar el DOM ni simular respuestas HTTP. Se utilizó una base SQLite temporal aislada, el catálogo de `seedDemo` y operaciones demo mediante los servicios reales del dominio. Ningún pago real ni dato de clientes.

Las imágenes PNG se capturaron directamente a escala CSS 1×; no tienen retoques. La interfaz conserva su aviso de demostración. El indicador de desarrollo se ocultó mediante la preferencia oficial de Next.js cuando estuvo disponible.
